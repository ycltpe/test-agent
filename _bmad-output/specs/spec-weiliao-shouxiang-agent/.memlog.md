- (capability) CAP-1 意图分类：intent=系统对每条买家消息输出单一意图标签+置信度（9 类枚举），作为唯一路由依据；success=标注测试集（≥1000 条，覆盖全部 9 类）准确率≥90%，分类延迟 P99<50ms
- (capability) CAP-2 重复追问识别：intent=识别同 session 同意图第 2 次及以后消息为 Follow-up Query 并计数；success=识别准确率≥95%（同义改写视为同意图）；计数存 Redis、TTL 30min；≥3 次 100% 触发转人工
- (capability) CAP-3 硬触发转人工：intent=命中硬触发（红线意图/图片语音输入/同意图追问≥3/负面词汇）即转交经纪人工作台并安抚买家；success=命中 100% 转人工零生成回答；买家收到安抚通知；送达延迟 P99<5s
- (capability) CAP-4 事实卡片缓存：intent=以『意图+房源ID+状态+价格分桶』为 key 缓存事实卡片（状态/价格桶/对口学校/最近3轮摘要），供模板或 LLM 消费时组装；success=缓存拦截率≥80%（口径：L1+L0 命中÷全部首次消息，压测验证）；TTL 5min、房源事件触发主动失效
- (capability) CAP-5 重复追问禁走缓存：intent=Follow-up Query 必须进入 LLM 链路生成带上下文的安抚性回应；success=同 session 同意图第 2 次消息 100% 走 LLM（Langfuse 可验证）；响应与首次缓存响应文本相似度<0.8
- (capability) CAP-6 LLM 受控生成：intent=对未命中缓存且非红线的消息，以事实卡片+上下文+生成约束调 OpenAI 生成；success=生成不虚构事实卡片外数据；首 token 到达 P99<1.5s
- (capability) CAP-7 生成内容审核：intent=LLM 生成内容 100% 经风控中台后置审核后才可发送；success=审核通过率≥95%（全量放行门槛）；不通过时模板兜底、服务无中断
- (capability) CAP-8 OpenAI 故障降级：intent=OpenAI 返回 429/5xx/超时（>1.8s）时自动切换模板兜底并在恢复后 10% 步进切回；success=切换时间<100ms；降级期间服务不返回 5xx；事件写 Langfuse 并告警
- (capability) CAP-9 AI 身份披露：intent=Agent 全程以『AI 助手』身份应答、绝不伪装真人经纪人，转人工后切换为经纪人姓名/头像；success=100% Agent 响应携带 AI 标识；生成文本不含『我是这套房的经纪人』类表述（风控审核范围）
- (capability) CAP-10 会话状态一致性：intent=维护 Redis 会话状态（意图历史/追问计数/事实卡片引用/handoff 状态），多实例读写一致；success=TTL 30min；并发写无竞态（原子操作/分布式锁）；过期后会话从零初始化无残留
- (decision) Why 定为『解决痛点』：安居客微聊首响真人响应分钟级（高峰/夜间小时级），高意向买家流失、经纪人 60-70% 时间耗在重复问答、敏感问题口径不合规
